# SewaJas Branding Assets

## Logo

Letakkan file logo resmi SewaJas di direktori ini dengan nama:

```
logo.png
```

Format yang disarankan:
- PNG dengan transparansi
- Ukuran minimal 512x512px
- Rasio aspek 1:1 (square) atau 4:3

Setelah logo diletakkan, invoice PDF akan otomatis menggunakan logo ini.

Jika logo belum diletakkan, sistem akan menggunakan fallback logo "SJ" gradient.
